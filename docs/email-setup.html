How to Set Up Email in MedChart

Don't worry if you've never set up email on a website before. This guide walks you through it, one step at a time.

MedChart sends emails for password resets, password changes, new account requests, and account approvals or denials. You only need one email sending method.

Start with PHP Mail. It's the easiest choice if your web host already supports it. SMTP is optional, and you can switch back at any time.

Option 1 — PHP Mail (easiest)

PHP Mail asks your hosting server to send the message. You don't have to enter a separate email server or password, provided your hosting company allows PHP mail delivery.

  1. Open your MedChart files using your hosting File Manager or FTP program.
  2. Find secret/mail.php and open it in a plain-text editor.
  3. Look for the method setting. It should say:
'method' => 'mail',
  1. Save the file if you made a change.
  2. Log in to MedChart as an administrator. Open Administration → Administrator Notifications.
  3. Enter your administrator email address and click Save Email. Then click Send Test Email.
  4. Check that inbox, including the Spam or Junk folder.
Did the email arrive? You're done. There is no need to configure SMTP.

If nothing arrives, ask your hosting company whether your account supports PHP's mail() function. You can also try SMTP below.

Option 2 — SMTP (optional)

SMTP means that MedChart connects to an email server to send your messages. Your hosting company or email provider supplies the settings.

Step 1 — Find your email server details

Look in your hosting control panel under Email Accounts, Connect Devices, or Mail Client Settings. If you can't find them, ask your provider for its outgoing SMTP settings.

Setting What to enter
SMTP host Server address, such as mail.example.com
Port Usually 587 or 465; use what your provider specifies
Security starttls (commonly port 587) or ssl (commonly port 465)
Username Often your full email address
Password Email account password or a special app password supplied by your provider
From email The sender address authorized by your email provider

Step 2 — Open the settings file

Open secret/mail.php. Change 'method' => 'mail' to 'method' => 'smtp'.

Step 3 — Enter the settings

Here is an example only. Replace every example value with your provider's actual details. Keep the quotes and commas. 

'method'     => 'smtp',
'from_email' => 'medchart@example.com',
'from_name'  => 'MedChart',
'host'       => 'mail.example.com',
'port'       => 587,
'security'   => 'starttls',
'username'   => 'medchart@example.com',
'password'   => 'YOUR_EMAIL_PASSWORD',
Don't copy these example values and expect them to work. example.com is not your email server. Also, never publish your real SMTP password in a forum post or public repository.

Step 4 — Save and test

Save secret/mail.php, return to MedChart Administration, save the administrator email address, and click Send Test Email. Check your inbox and Spam/Junk folder.

Which port and security setting?

Port Usually paired with
587 starttls — encrypted after connecting
465 ssl — encrypted from the beginning
1025 none — local Mailpit testing only
25 Often blocked; avoid unless your provider specifically instructs you to use it
Gmail note: A normal Gmail password generally won't work with older basic SMTP authentication. Some eligible Google accounts can use an app password; others require OAuth2. This MedChart SMTP implementation does not support OAuth2, so Gmail may not be suitable for your setup.

Testing locally on Windows with Mailpit

Mailpit is a free local email catcher. It lets you test MedChart without sending real emails to anyone.

  1. Start mailpit.exe on your computer. Leave its window running.
  2. Open http://localhost:8025 to view your test inbox.
  3. Open secret/mail.php and use these settings:
'method'     => 'smtp',
'from_email' => 'medchart@localhost.test',
'from_name'  => 'MedChart',
'host'       => '127.0.0.1',
'port'       => 1025,
'security'   => 'none',
'username'   => '',
'password'   => '',
  1. Save the file. Open Administration → Administrator Notifications in MedChart.
  2. Save an administrator email address and click Send Test Email.
  3. Check the Mailpit inbox. You should see the message appear.
Important: The none security option is for local testing with Mailpit, not for sending real email over the internet. The SMTP implementation refuses passwords over an unencrypted connection.

If your test email doesn't arrive

  • PHP Mail: Check Spam/Junk, then ask your web host if PHP mail() is enabled.
  • SMTP: Double-check the host, port, security setting, username, and password. Even one wrong character can stop delivery.
  • Port 465: Use ssl, not starttls, unless your provider tells you otherwise.
  • Port 587: Usually use starttls.
  • Mailpit: Confirm Mailpit is running and that port 1025 is available.
  • Sender rejected: Use a from_email address your provider allows.
  • Still stuck? Ask your hosting provider: “What are the outgoing SMTP settings for my email account, and do you allow authenticated SMTP connections from PHP websites?”

Remember: a successful send means the mail server accepted the message; it does not guarantee that a real recipient will receive it.

Keep your email settings private

The secret/mail.php file can contain your SMTP password. Keep it in MedChart's protected secret directory, and do not share it or upload it to a public GitHub repository. Your website should use HTTPS when deployed publicly.

You can always switch back to PHP Mail by setting 'method' => 'mail'. No database changes are needed to switch between the two delivery methods.
